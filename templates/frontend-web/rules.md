Project rules (web front end):
- Follow the existing component structure, naming and styling approach; do not reformat files you do not change.
- Write component tests before the code and run the project's test script before closing a step.
- All visible text goes through the project's translation mechanism when it has one; never hard-code user-facing strings.
- No secrets or environment files in commits. Do not add dependencies without saying why in the step note.
