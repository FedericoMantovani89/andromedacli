Project guidance for this web front-end plan:
- Write the goal of each activity as one visible result: a component, a page, a flow. Name the files or folders it lives in and how to check it (a test, a screen).
- Two activities must not edit the same component or stylesheet at once: split by screen or by component.
- Say in the goal which documents the work changes (README.md, CHANGELOG.md) so the last step updates them.
